## sudachi とは

プログラミングの勉強を始めたとき、「IT仲間とつながりたい」「学習を共有したい」と思ったことはありませんか？

しかし初学者にとっては、Qiita のような場所への投稿やコミュニティへの参加は **心理的なハードル** が高く、同じ目標を持つ仲間と出会う機会が限られています。

そこで私たちは、気軽に学習内容を共有でき、さらに仲間ともつながれる IT特化型SNS **「sudachi」** を開発しました。

## こだわった機能

### 1. 開発メンバー募集機能

> 「身近な募集も見つからないし、見つかっても自分に合うかどうかもわからない」
> 「一緒に開発したいけれど、相手がどんな勉強をしている人なのか分からない」

そんな課題に対して、募集を通常の投稿とは分けて **専用ページ** にまとめました。

- 使う技術・希望する学習段階・初心者歓迎かどうかを見て、自分に合った募集を自分の目で選べる
- 募集から募集者のプロフィールへそのまま移動し、これまでの学習投稿を確認できる
- 何を学んでいる人なのかを知った上で、安心して「興味あり」を送れる
- 「興味あり」をきっかけに、DM で実際のやりとりが始められる

### 2. 相棒キャラクター

> 「一人だと学習が続かない」

そんな課題に対して、投稿するたびに経験値がたまり、**あなたと一緒に成長する相棒キャラクター** を実装しました。

経験値がたまっていく過程そのものが継続する楽しさにつながり、学習の継続を後押しします。

- 投稿1回につき経験値 +10
- 経験値が一定たまると次の段階へ進化
- マイページで現在の段階と、次の進化までの経験値を確認できる

## 画面と使い方

| 画面 | できること |
|---|---|
| タイムライン | みんなの学習投稿を見て、ナイスを送る |
| 投稿作成 | 学習内容を投稿する（画像は任意）。投稿を終えると相棒キャラクターに経験値が入る |
| 募集 | 開発メンバーの募集を一覧・作成し、気になる募集に「興味あり」を送る |
| メッセージ | ユーザー同士で DM をやりとりする |
| マイページ | 自分の投稿と相棒キャラクターの成長を確認する |

## 技術スタック

短期間で開発するため、モダンで実装しやすい構成を選びました。

| 領域 | 技術 |
|---|---|
| フロントエンド | React / TypeScript / Vite / React Router |
| バックエンド | FastAPI / SQLAlchemy |
| 認証・DB・画像ストレージ | Supabase（Auth / PostgreSQL / Storage） |
| ホスティング | Vercel（フロントエンド）/ Render（バックエンド） |
